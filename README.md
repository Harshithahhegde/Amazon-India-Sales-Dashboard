# Amazon India Sales & Profit Dashboard

## Project Overview
This project focuses on analyzing Amazon India sales data and building an interactive management dashboard using Microsoft Excel.

The dashboard helps understand business performance through sales, profit, product categories, order status, payment methods, fulfilment methods, and geographic analysis.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Excel Charts
- KPI Calculations
- Data Analysis

## Key Performance Indicators
- Total Sales
- Total Profit
- Total Orders
- Total Units Sold
- Average Order Value
- Profit Margin
- Return Rate
- Cancellation Rate

## Business Analysis
1. Overall Sales & Profit Performance
2. Category & Product Performance
3. Order Status & Revenue Loss
4. Payment Method Performance
5. Fulfilment Performance
6. Geographic Performance

## Key Features
- Monthly sales and profit trend analysis
- Top 10 products by sales
- Category-wise sales and profit
- Order status analysis
- Payment and fulfilment analysis
- State-wise business performance

## Dataset
The project uses an Amazon India order dataset containing 10,000 records.

## Project Files
- Amazon_India_Sales_Profit_Dashboard.xlsx – Completed Excel dashboard and analysis.
- Raw data and analysis worksheets are included in the workbook.

## Objective
To transform raw sales data into meaningful business insights and support data-driven decision-making.
